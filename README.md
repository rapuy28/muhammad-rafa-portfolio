# Muhammad Rafa Q — Portfolio

A responsive personal portfolio for Muhammad Rafa Qanthara, built as a static HTML page with Tailwind CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. Tailwind CSS and the font are loaded from their CDNs.

## Deploy to Vercel

Import this repository in Vercel and use the repository root as the project root. No build command or output directory is required for this static site.
